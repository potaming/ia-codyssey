# 영화 티어리스트 기획서

## 1. 누가 쓰나
- 내가 본 영화를 취향대로 정리하려는 개인 사용자 1명.
- 회원가입이나 온라인 공유 없이, 자신의 브라우저에서 사용한다.

## 2. 무엇을 하려고
- 영화 8편을 출발점으로 삼아, 내가 본 영화를 1~5점 등급으로 분류한다.
- 필요할 때 영화별 한 줄 감상평을 남기고, 새로운 영화도 추가해 나만의 영화 목록을 관리한다.

## 3. 화면과 동작
- 5점부터 1점까지 다섯 개의 등급 영역을 표시한다. 영화 카드가 속한 영역이 해당 영화의 점수다.
- 처음에는 `아이디어.md`에 나온 영화 8편을 보여준다. 초기 점수는 외부 평점이 아닌 **시연용 고정 분류**로 지정한다.
  - 5점: 기생충, 인터스텔라, 센과 치히로의 행방불명
  - 4점: 라라랜드, 어벤져스: 엔드게임, 타이타닉
  - 3점: 범죄도시, 토이 스토리
  - 2점·1점: 처음에는 비워 둔다.
- 영화는 다른 점수 영역으로 **드래그 앤 드롭**하거나, 카드의 `+` / `−` 버튼으로 한 단계씩 이동한다.
- 영화 제목과 최초 등급을 입력해 새 카드를 추가한다. 추가할 때 한 줄 감상평을 선택적으로 입력할 수 있다. 감상평을 비워 두어도 추가할 수 있다. 영화 제목 검색·자동완성·포스터는 사용하지 않는다.
- 영화 카드의 `의견 보기`를 눌러 감상평을 직접 작성·수정할 수 있다. 감상평을 쓰지 않아도 된다.
- 영화 카드를 삭제할 수 있다.
- `전 단계로`를 누르면 직전 편집 작업(추가·삭제·점수 변경·감상평 적용)을 취소한다. 실행 취소한 결과도 자동 저장한다.
- 영화 추가·삭제, 점수 이동, 감상평 적용 직후 현재 목록과 감상평이 브라우저 `localStorage`에 자동 저장된다. 별도의 `저장하기` 버튼은 제공하지 않는다.
- 화면 상단에 `✓ 자동 저장됨 · 이 브라우저` 상태를 표시한다. 저장에 실패하면 `⚠ 자동 저장 실패`를 표시한다.
- 같은 브라우저에서 다시 열면 마지막으로 자동 저장된 상태가 유지된다.
- 모든 평가를 초기 상태로 되돌리는 기능은 만들지 않는다.

## 4. 필요한 자료
- `아이디어.md`의 8개 영화 제목: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리.
- 각 영화의 시연용 초기 등급(위 3번에 명시).
- HTML·CSS·JavaScript가 하나로 포함된 HTML 파일 1개.
- 데이터를 저장할 브라우저 `localStorage`. 외부 API, 이미지, 검색 엔진, 서버는 사용하지 않는다.

## 5. 완성 기준
1. 처음 열면 **영화 8개가 모두** 지정된 3~5점 영역에 표시된다.
2. 영화 8개를 각각 다른 별점 영역에 옮길 수 있다(드래그 앤 드롭).
3. 영화 카드의 `+` / `−` 버튼을 누르면 한 단계씩 이동한다. 점수는 1~5점 범위 밖으로 나가지 않는다.
4. 제목과 점수를 입력해 새 영화를 추가하면 지정한 영역에 나타난다. 추가할 때 감상평을 선택적으로 입력하면 해당 영화 카드에 저장되며 `의견 보기`에서 확인할 수 있다. 감상평을 비워 두어도 추가되지만 제목이 비어 있으면 추가되지 않는다.
5. `의견 보기`를 누르면 영화 카드에서 감상평을 확인·작성·수정할 수 있다. 빈 감상평도 허용한다.
6. 영화를 삭제하면 해당 카드가 화면에서 사라진다.
7. `전 단계로`를 누르면 직전 편집 작업이 취소되고 그 결과도 자동 저장된다.
8. 추가·삭제·점수 변경·감상평 적용 직후 별도의 저장 버튼 없이 데이터가 자동 저장된다.
9. 저장에 성공하면 화면 상단에 `✓ 자동 저장됨 · 이 브라우저`라고 표시된다. 저장 실패 시에는 실패 메시지를 표시하며 성공했다고 안내하지 않는다.
10. 같은 브라우저에서 파일을 다시 열면 영화 추가·삭제, 점수 이동, 감상평이 마지막으로 자동 저장된 상태로 나타난다.
11. 외부 파일·API·서버·인터넷 연결 없이 HTML 파일 하나만 열어 실행할 수 있다.

## 아직 정하지 않은 것
- 없음. 초기 등급은 개발 비교를 위한 예시 값으로 선택했으며, 실제 영화 평점을 의미하지 않는다.
